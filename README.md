# Java Console Calculator

A simple console-based calculator developed using Java.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Multiple calculations using a loop
- User input using Scanner

## Technologies Used

- Java
- JDK
- Scanner
- VS Code

## How to Run

Compile the program:

javac Calculator.java

Run the program:

java Calculator
